# v0.1.3 · 跨平台兼容与补装保护

本次补丁完善Windows/Linux使用与已有应用补装保护，基础工程继续委托Vite+官方模板。

## 更新内容

- 恢复报告提供PowerShell与POSIX命令，按当前系统显示；保留原始参数供核对。
- 规范操作系统临时根的真实路径，固定CLI入口LF换行，明确Linux非目录祖先占用的提示。
- 空补装仅在工作区配置确有变化时格式化；已有模型插件在安装引擎前拒绝重复配置。
- 完善受控安装失败重试、KEY与原件备份保护，增加本地tgz隔离安装验收入口。

## 使用

```powershell
vp dlx -- @adui/viteplus-starter@0.1.3
pnpm dlx @adui/viteplus-starter@0.1.3
```

无参数进入与Vite+一致的选择向导。基础工程支持Vue/React、TS/JS及Monorepo，UI、CSS、大屏、3D和模型保护按应用配置；包内包含本地normalize.css及统一Logo。

## 验证范围

- Windows Node22.18.0、Linux x64 Node26.13.0候选各301项测试通过；实际tgz安装、命令shim、官方混合工程和模型双入口构建通过。
- 真实Three embedded/external补装及各8项保护检查通过，179份文件内容和修改时间保持；实际发布包仅README文字与该候选不同，其余91份文件原字节一致。
- 正式包另行完成清单、SHA-512、隔离安装、帮助和Vue/React预览复核；公开上传及完整性结果以发布记录为准。
- macOS兼容逻辑已有受控覆盖，尚无原生设备验收；其他Linux架构、全部插件组合及浏览器效果不计为本轮通过。
