## 修复

- Vue/React 新建应用使用外置密钥时，错误密钥后换成正确密钥会清除旧提示，避免模型已经显示但仍提示认证失败。
- Cesium 预设更新为 1.147.0，修复旧聚合入口与新解析的 engine 依赖不匹配导致的缺失导出构建错误；保留已有项目拒绝自动升级的保护。

## 使用文档

- 统一 Windows、macOS、Linux 的使用入口。
- 增加 Three.js、CesiumJS、Babylon.js 加载加密 GLB 的代码示例，以及 Vue/React 挂载清理和外置密钥用法。
- 本地 tgz 使用绝对路径，避免 dlx 从缓存目录解析相对路径。

## 使用

```sh
vp dlx -- @adui/viteplus-starter@0.1.4
# 或
pnpm dlx @adui/viteplus-starter@0.1.4
```

已有生成项目不会随 CLI 更新自动改写。应用插件仍位于 `src/plugins` / `build/plugins`，基础工程继续使用 Vite+ 官方模板。

## 验证

- Windows/Linux 各305项测试通过，实际归档安装、官方工作区生成、模型加密构建及重复操作保护通过。
- 三个引擎的 README 示例已参与实际类型检查和生产构建，包含 Cesium 静态资源与真实 GLB 的 `.adui` 解密检查。

完整候选记录见[0.1.4验收文档](https://github.com/adui-studio/viteplus-starter/blob/main/docs/CANDIDATE_0_1_4.md)。客户端内置密钥用于提高直接复用门槛，不保证无法逆向提取。
